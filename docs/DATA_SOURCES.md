# 数据来源与核实说明

本文件说明徽知平台文化数据的来源、核实方式与可信度分级。
所有事实性内容均登记在 `data/sources.json`，实体与关系通过 `source_ids` 字段引用。

---

## 一、可信度分级

| 级别 | 类型 | 说明 |
|---|---|---|
| A | UNESCO 世界遗产中心 | 世界遗产条目的官方认定信息 |
| B | 国家级政府机构 | 国务院文件、文化和旅游部、中国非物质文化遗产网 |
| C | 地方人民政府与官方媒体 | 黄山市人民政府、黄山风景区管委会、黄山市文化和旅游局、光明网、新华网、学习强国、中国文明网、人民日报客户端 |
| D | 学术与专业出版物 | 北京周报等 |
| E | 百科条目 | 仅在 A–D 未覆盖时作补充，并在来源说明中明确标注其权威性较低 |

本项目**优先使用 A–C 级来源**；E 级来源仅用于 A–D 未覆盖的细节（如许国石坊的国保批次），且在 `sources.json` 的 `note` 字段中明确写出「权威性低于官方来源」。

## 三、核实方式

1. **先检索核实，再写入数据**：每条事实在写入 `entities.json` / `relations.json` 前，均通过检索获取官方或权威来源页面确认，不使用未经核实的推测内容。
2. **每条实体与关系都必须带来源**：`source_ids` 字段不可为空 —— 这一要求已由 `tests/test_data_integrity.py` 固化为自动化测试，缺失来源会直接导致测试失败。
3. **来源引用有效性由程序校验**：`src/data/loader.py` 在加载时检查所有 `source_ids` 是否指向 `sources.json` 中真实存在的条目，断链会抛出异常。
4. **关键事实有回归测试**：世界遗产编号与年份、非遗批次与申报地区、牌坊数量、人物评选名次等关键事实均在 `tests/test_data_integrity.py` 中设定了断言，数据被误改会立即暴露。

## 四、已知的数据取舍

| 情况 | 处理方式 |
|---|---|
| 同一事实在不同官方来源中口径不一 | 采用更权威或更具体的来源，并在实体 `attributes` 中保留口径说明。例如黄山千米以上高峰数量，黄山风景区管委会口径为 88 座，UNESCO 表述为 77 座，本项目采用景区管委会口径并在来源中标注。 |
| 行政区划变迁 | 明确标注现行归属。如婺源县标注为「徽州婺源（今属江西省上饶市）」，绩溪县标注为「徽州绩溪（今属安徽省宣城市）」。 |
| 无法核实的内容 | **不写入数据集**，宁可减少实体，也不引入无出处内容。 |
| 民间传说类内容 | 仅在明确标注为「相传」的前提下收录，并给出出处。如徽州一品锅的乾隆赐名传说。 |

## 五、图片素材

图片取自 **Wikimedia Commons**，逐一登记授权协议、作者与原始链接，汇总于
`assets/images/manifest.json`（机器可读）与 `assets/images/CREDITS.md`（人工可读）。

**P3 实测结论：本机对 Wikimedia 存在 SNI 域名级阻断。** `commons.wikimedia.org`
与 `upload.wikimedia.org` 的 DNS 被污染到 `103.102.166.x`（非 Wikimedia 真实网段），
直连、走代理、脱离沙箱三种方式在 TCP 层一律握手超时（`code=000`）；
而同一台机器上 `dumps.wikimedia.org`（真实 IP `208.80.154.242`）返回 `200`，
用真实 IP + `--resolve` 覆盖 commons/upload 仍失败——**证明是按域名（SNI）拦截，而非整体断网**。
对照：`ihchina.cn`、`mirrors.aliyun.com` 正常，`github.com` 与 Wikipedia 全站不可达。

**因此改走一组免费中转池**（内容仍来自 Wikimedia，授权与作者以 Commons API 为准）：

| 用途 | 中转服务 |
|---|---|
| 元数据（文件名 / 许可 / 作者） | 中转池轮换：`api.microlink.io` / `api.allorigins.win` / `api.cors.lol` / `api.codetabs.com`，带冷却退避 |
| 图片字节 | `wsrv.nl`（images.weserv.nl）图片代理 → 回源 upload.wikimedia.org |

> 这些免费中转都会间歇性限流（常见 429 / 500 / 503 / 520 / 522），
> 因此脚本维护一个池：按「近期成功率 + 冷却状态」轮换，单点被限流不会卡住整批抓取。

**已收录 15 张图片**，覆盖西递、呈坎、唐模、棠樾、许村、渔梁、承志堂、屯溪、许国石坊、
黄山、齐云山、南屏、徽派建筑、徽州民居、胡庆余堂；许可为 CC0 / CC BY / CC BY-SA / 公有领域，
逐条登记于 `CREDITS.md`。

**收录门槛有三条**：自由授权、与实体确实相关、**Commons 上登记了作者**。
相关性把关对「徽州牌坊」「徽州祠堂」这类带地域的建筑类型名会额外要求出现徽州一府六县的地名，
用于挡住同名异地（如无锡惠山祠堂）与同物异指（如白云寺院门）的候选。
另有 14 个实体因找不到同时满足三条的图片而**不放图**，清单见 `CREDITS.md`。

**授权白名单**：仅接受 CC0 / CC BY / CC BY-SA / Public domain / GFDL；
**主动拒绝 NC（非商用）与 ND（禁演绎）**，避免授权瑕疵。图注由人工对照实际图片内容写定。

说明与复现方式详见 `assets/images/README.md`。
