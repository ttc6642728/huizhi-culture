徽知 · Huizhou Culture Explorer —— 运行方法

================================================
一、环境要求
================================================
- Python 3.12 或更高版本（查看方式：命令行执行 python --version）
- 首次安装依赖需要联网（约 150-250 MB），装好之后运行不再需要网络

================================================
二、首次运行（三步）
================================================
在本项目文件夹内打开命令行，依次执行：

  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
  streamlit run app.py

浏览器会自动打开 http://localhost:8501
（若 8501 端口被占用，命令行会给出实际地址）

================================================
三、日常运行（已装好依赖后）
================================================
在本项目文件夹内执行：

  .venv\Scripts\activate
  streamlit run app.py

================================================
四、关于 API Key（很重要）
================================================
不需要配置任何 Key 也能正常使用！

本项目的问答有三层后端，会自动降级：
  1. Dify 知识库/工作流    —— 需要配置 .env
  2. OpenAI 兼容大模型     —— 需要配置 .env
  3. 本地检索式（离线）    —— 无需任何配置

未配置 .env 时自动使用第 3 层：纯离线运行，问答依旧带来源引用。
页面会明确显示当前使用的是哪个后端，不会把本地检索伪装成大模型。

若要启用真实大模型，把 .env.example 复制为 .env 并填入自己的密钥即可。
注意：.env 含密钥，绝不要随项目一起发送给别人。

================================================
五、其它命令
================================================
  pytest                              运行全部测试（437 项，约 30 秒，不联网）
  python scripts/validate_data.py     数据校验
  python scripts/evaluate.py          离线质量评估
